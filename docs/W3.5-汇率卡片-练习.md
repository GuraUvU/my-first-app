## 接口说明（我已经测通）

```
GET https://open.er-api.com/v6/latest/USD
```

返回（节选）：

```json
{
  "result": "success",
  "base_code": "USD",
  "time_last_update_utc": "Thu, 12 Nov 2026 00:02:31 +0000",
  "rates": { "CNY": 6.685797, "EUR": 0.899865, "JPY": 159.51378, "GBP": 0.752421, ... }
}
```

三个要点：

1. `base_code` 是美元，所以 `rates` 里所有数字都是「**1 美元 = 这么多**」
2. `result` 字段是 `"success"` 才代表成功（失败时是 `"error"`，并带 `error-type`）
3. 免费、不用 key、**允许浏览器跨域**（`access-control-allow-origin: *`），国内可直连

## 第 2 步：加两个 state

在「每日一句」的 state 下面加：

```tsx
  const [rates, setRates] = useState<Record<string, number>>({});
  const [updatedAt, setUpdatedAt] = useState("");
```

🆕 **新东西 1**：`useState<Record<string, number>>({})`
- `{}` 是初始值：一个空对象
- `<Record<string, number>>` 是 TypeScript 的类型标注，意思是「这个对象里，键是字符串、值是数字」。写它的好处是：`rates.CNY` 时编辑器知道它是数字，能自动提示 `toFixed`

> 这个尖括号不是你漏写的 JSX，是 TS 的**泛型**。暂时不用深究，抄着用就行。

---

## 第 3 步：写 `loadRates`，先只在控制台看

在 `loadQuote` 函数下面加一个：

```tsx
  async function loadRates() {
    try {
      setUpdatedAt("");
      const res = await fetch("https://open.er-api.com/v6/latest/USD");
      if (!res.ok) {
        throw new Error("请求失败：" + res.status);
      }
      const data = await res.json();
      console.log(data);
      if (data.result !== "success") {
        throw new Error("接口返回失败：" + data["error-type"]);
      }
      // TODO: 第 4 步在这里 setRates / setUpdatedAt
    } catch (error) {
      console.error(error);
      setUpdatedAt("获取失败，请稍后再试");
    }
  }
```

🆕 **新东西 2**：`data["error-type"]`
- 这个字段名带个横杠 `-`，不能写成 `data.error-type`（会被当成减法）
- 带特殊字符的键，只能用方括号 + 字符串：`data["error-type"]`

**再让它在页面打开时跑一次**，在原来的 `useEffect` 里加一行：

```tsx
  useEffect(() => {
    loadQuote();
    loadRates();
  }, []);
```

**验收**：F12 → Console → 刷新 → 能看到第二个对象，展开 `rates` 里有 `CNY: 6.68...`。

## 第 4 步：显示出来

**① 在文件顶部（`cards` 数组下面）定义要显示的币种：**

```tsx
const shownCurrencies = ["CNY", "EUR", "JPY", "GBP"];
```

**② 第 1 步那张卡片的正文，换成遍历：**

```tsx
          <div className="mt-3 space-y-1.5">
            {shownCurrencies.map((code) => (
              <p key={code} className="text-sm leading-8 text-zinc-200">
                1 美元 = {rates[code] ? rates[code].toFixed(2) : "—"} {code}
              </p>
            ))}
          </div>
          <p className="mt-3 text-xs text-zinc-500">
            更新于：{updatedAt ? new Date(updatedAt).toLocaleString("zh-CN") : "加载中……"}
          </p>
```

🆕 **新东西 3**：`rates[code]` 和 `toFixed`
- `rates` 是个对象，取值用 `rates["CNY"]`；因为 `code` 是变量，所以写成 `rates[code]`
- `{rates[code] ? ... : "—"}`：数据还没到时不显示 `undefined`，先显示横线
- `.toFixed(2)` 把 `6.685797` 变成字符串 `"6.69"`（保留两位小数，四舍五入）

**③ 第 3 步的 TODO 处，补上存数据：**

```tsx
      setRates(data.rates);
      setUpdatedAt(data.time_last_update_utc);
```

**验收**：卡片显示四行汇率 + 更新日期，刷新页面数字基本不变（汇率一天更新一次），但底部的更新时间会变成当天。

## 关于缓存：这次**不要**加随机参数

还记得「换一句」为什么要加 `?_=时间戳` 吗？这次相反。

这个接口的响应头是 `Cache-Control: public, max-age=3600`——意思是「一小时之内，浏览器直接用本地副本，别来问我」。

对汇率来说这是**好事**：汇率一天只变一次，一小时内不重复请求既省钱又快。所以这里**保持原样，不加随机参数**。

记一下这个判断标准：

| 数据特性 | 是否要防缓存 |
|---|---|
| 每次都想要新内容（随机金句、搜索结果） | 要，加 `?_=Date.now()` |
| 一天/一小时才变一次（汇率、天气、榜单） | 不要，让它缓存 |

## 常见错对照表

| 现象 | 原因 |
|---|---|
| 四行都是「—」 | `setRates` 没调用，或 `data.rates` 写成了 `data.rate` |
| 页面白屏 + 控制台 `Objects are not valid as a React child` | 直接把整个 `rates` 对象渲染了，要用 `rates[code]` |
| `rates[code]` 报类型错误 | 忘了第 2 步的 `<Record<string, number>>` |
| 时间显示 `Invalid Date` | `toLocaleString` 收到空字符串，确认 `updatedAt` 有值再格式化 |
| 一直「加载中……」 | `loadRates()` 没在 useEffect 里调用，或接口被网络拦了（F12 Network 看红色） |

## 这一课真正学到的东西

不是「又调了一个接口」，而是：

- **同一个套路能复用**：发请求 → 检查 `res.ok` → 取字段 → 存 state → 渲染
- **对象和数组的差别**：`cards` 是数组（用 `map` 直接循环），`rates` 是对象（要先有 `shownCurrencies` 这个键的列表，才能循环）
- **缓存不是 bug**：看数据变化频率决定要不要绕开它
