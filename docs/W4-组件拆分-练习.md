# 第 1 次：拆 `<Card>`

## 概念：组件就是一个返回 JSX 的函数

你现在已经有 5 个“卡片”，但它们是**复制粘贴**出来的结构。组件就是把这段结构**起个名字**，然后像标签一样用：

```tsx
<Card title="我在学什么" lines={["...", "..."]} />
```

传给组件的数据叫 **props**（属性），组件内部当成参数接收。

> 组件名**必须大写开头**（`Card` 不是 `card`）。小写的会被 React 当成 HTML 标签 `<card>`，浏览器不认识。

## 步骤

**① 新建文件夹和文件**

```
app\components\Card.tsx
```

> `app/components/` 里放的文件**不会变成页面**。只有 `page.tsx`、`layout.tsx`、`route.ts` 这几个固定名字才创建路由。所以放心建。

**② 写组件（骨架，3 处 TODO 你来填）**

```tsx
type CardProps = {
  title: string;
  lines: string[];
};

export default function Card({ /* TODO 1: 这里解构 title 和 lines */ }: CardProps) {
  return (
    <div className="rounded-2xl border border-white/10 bg-white/[0.04] p-6 transition-colors hover:border-white/25 hover:bg-white/[0.07]">
      <h2 className="text-lg font-medium text-white">{/* TODO 2: 显示标题 */}</h2>
      <div className="mt-3 space-y-1.5">
        {lines.map((line) => (
          {/* TODO 3: 和原来一样，<p key={line} className="text-sm leading-6 text-zinc-400">{line}</p> */}
        ))}
      </div>
    </div>
  );
}
```

**③ 回到 `page.tsx`，把 `cards.map` 那段换掉**

原来（约 10 行）：

```tsx
{cards.map((card) => (
  <div key={card.title} className="rounded-2xl ...">
    <h2 className="...">{card.title}</h2>
    <div className="mt-3 space-y-1.5">
      {card.lines.map((line) => (
        <p key={line} className="...">{line}</p>
      ))}
    </div>
  </div>
))}
```

改成：

```tsx
{cards.map((card) => (
  <Card key={card.title} title={card.title} lines={card.lines} />
))}
```

**④ 在 `page.tsx` 顶部加 import**

```tsx
import Card from "./components/Card";
```

> `./` 表示“当前文件所在目录”。`page.tsx` 在 `app/`，所以 `./components/Card` 就是 `app/components/Card.tsx`。

**验收**：
- 页面看起来**一模一样**（三张卡的样式、间距都没变）
- 终端没有报错
- `page.tsx` 少了约 8 行

**常见错**：

| 报错 | 原因 |
|---|---|
| `Card is not defined` | 忘了第 ④ 步的 import |
| `props is not defined` | 忘了 TODO 1 的解构，写成 `function Card(props)` 却直接用 `title` |
| `Each child in a list should have a unique "key"` | `key` 从 map 里挪到了组件标签上，别写到 `Card` 内部 |
| 页面空白 + `Element type is invalid` | 组件文件忘了 `export default` |

# 第 2 次（续）：拆 `<Modal>`

Modal 特殊在：它自己**不决定**要不要显示，显示与否由父组件控制。

```tsx
type ModalProps = {
  open: boolean;
  onClose: () => void;
};

export default function Modal({ open, onClose }: ModalProps) {
  if (!open) return null;

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/70 p-5 backdrop-blur-sm" onClick={onClose}>
      <div role="dialog" aria-modal="true" className="..." onClick={(event) => event.stopPropagation()}>
        <p className="text-lg font-medium text-white">不要点这个</p>
        <button type="button" onClick={onClose} className="...">彳亍</button>
      </div>
    </div>
  );
}
```

`page.tsx` 里：

```tsx
<Modal open={open} onClose={() => setOpen(false)} />
```

**两个知识点**：

1. `if (!open) return null;` —— 组件可以返回 `null`，表示“什么都不渲染”。比 `{open && (...)}` 更好读。
2. `onClose` 是个**函数**，从父组件传进来。子组件不关心“关掉之后干什么”，它只负责通知“用户要关了”。这叫**回调（callback）**，是组件通信的核心。

# 第 3 次：加 `/about` 页面

**① 新建 `app\about\page.tsx`**（目录名就是网址，访问 `/about`）

```tsx
import Link from "next/link";

export const metadata = {
  title: "关于我 | 我的 AI 实验田",
};

export default function AboutPage() {
  return (
    <div className="flex min-h-screen flex-col bg-[#0b0b0f] px-5 py-16 text-zinc-100">
      <main className="mx-auto w-full max-w-3xl">
        <h1 className="text-2xl font-semibold">关于我</h1>
        <p className="mt-4 text-zinc-400">（这里写两句：你是谁、在做什么）</p>
        <Link href="/" className="mt-8 inline-block text-sm text-zinc-300 underline">
          ← 回首页
        </Link>
      </main>
    </div>
  );
}
```

**② 首页底部加一个入口**（在「点这个」按钮旁边）

```tsx
import Link from "next/link";
...
<Link href="/about" className="rounded-full border border-white/15 px-6 py-2.5 text-sm text-zinc-200 hover:bg-white/10">
  关于我
</Link>
```

**三个知识点**：

1. **文件即路由**：`app/about/page.tsx` → 网址 `/about`，不用注册任何东西
2. **`<Link>` 而不是 `<a>`**：`Link` 是 Next 的客户端跳转，不会整页刷新，快得多
3. **`metadata`**：这个页面的 `<title>`，静态导出的页面也能带上

**验收**：首页点「关于我」→ 到 `/about` → 点「← 回首页」回来，全程不白屏。

> 静态站的路由我已经在 `next.config.ts` 里配好了 `trailingSlash`（只在导出模式生效），所以导出后会生成 `out/about/index.html`，腾讯云上直接访问 `/about` 就能打开。**你 push 之后我重新出包给你传。**

# 这一课真正学到的东西

| 概念 | 一句话 |
|---|---|
| 组件 | 一段 JSX 起个名字，就能重复用 |
| props | 父组件传给子组件的数据，子组件只读不改 |
| 回调 props | `onClose` 这种，让子组件“通知”父组件 |
| 状态归属 | 哪个组件用这个 state，就放在哪个组件里 |
| 文件即路由 | `app/xxx/page.tsx` 就是 `/xxx` |

拆组件这件事，新手最容易犯的错是**“为了拆而拆”**——把 5 行代码拆成 3 个文件，反而更难读。判断标准只有一个：**这段东西会不会被用到第二次，或者它是不是有自己独立的状态**。会，就拆；不会，留着。
