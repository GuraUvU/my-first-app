## 第 1 步：先加一张"假"卡片（不写逻辑）

**目标**：页面上多出第四张卡，内容是你手写的死文字。先让界面出现，再让它变聪明。

**改哪里**：`app\page.tsx` 第 52 行 `))}` 之后、第 53 行 `</section>` 之前，插入下面这段。

```tsx
          {/* 第四张：今日一句 */}
```

## 第 2 步：把文字换成"变量"（认识 useState）

**目标**：卡片不再显示死文字，而是显示两个变量。现在变量是空的，所以会显示"正在加载…"。

**改动 1**：第 21 行 `const [open, setOpen] = useState(false);` 下面加两行：

```tsx
  const [quote, setQuote] = useState("");
  const [source, setSource] = useState("");
```

> `useState("")` 里那个 `""` 是**初始值**，意思是"一开始是空字符串"。
> `setQuote` 是唯一能改变 `quote` 的函数。**不能写 `quote = "xxx"`**，那样页面不会更新。

**改动 2**：把第 1 步那张卡里的两行文字换掉：

```tsx
              <p className="text-sm leading-6 text-zinc-400">{quote || "正在加载…"}</p>
              <p className="text-xs leading-5 text-zinc-500">{source ? "—— " + source : ""}</p>
```

> `{quote || "正在加载…"}` 的意思是：`quote` 是空的就显示后面的文字。
> `{source ? "—— " + source : ""}` 的意思是：有出处才显示"—— 出处"，没有就显示空。

**验收**：页面显示「正在加载…」，出处那行是空的。**这是对的**，因为我们还没去网上拿数据。

**常见错**：`quote is not defined` → 变量加在了组件外面（必须在 `export default function Home() {` 的花括号里面）。

## 第 3 步：发请求，先只在控制台里看结果

**目标**：会从网上拿到数据，但先不显示，只在浏览器控制台打印出来。**这一步不碰界面**，是故意的——先看清楚数据长什么样。

**改动 1**：第 3 行改成（把 `useEffect` 加进 import）：

```tsx
import { useEffect, useState } from "react";
```

**改动 2**：在第 2 步那两行 state 下面，加：

```tsx
  useEffect(() => {
    async function loadQuote() {
      try {
        const res = await fetch("https://v1.hitokoto.cn/");
        const data = await res.json();
        console.log(data);
      } catch (error) {
        console.error(error);
      }
    }
    loadQuote();
  }, []);
```

**验收**：

1. 浏览器按 **F12** → 选「Console / 控制台」标签
2. 刷新页面（F5）
3. 控制台出现一个可以展开的对象，展开后能看到 `hitokoto: "大丈夫立世无所畏惧。"`、`from: "仙剑奇侠传四"` 这样的字段

**这几行在干什么**（先读一遍，不懂就问我）：

- `useEffect(..., [])`：页面打开后执行一次。`[]` 是"依赖数组"，空的表示"只跑一次"
- `async function`：里面可以用 `await`，意思是"等这件事做完再往下走"
- `fetch(url)`：发网络请求，拿到的是**响应对象**，还不是数据
- `res.json()`：把响应体解析成 JS 对象（这一步也要 `await`）
- `try / catch`：网络断了、服务器挂了，代码会跳到 `catch`，不会白屏

**常见错**：
| 现象 | 原因 |
|---|---|
| 控制台红色 `CORS` / `Failed to fetch` | 网络或浏览器拦截，先换网络试；再不行告诉我 |
| 控制台没东西 | 没刷新页面；或 `loadQuote();` 这一行漏了 |
| `useEffect is not defined` | 第 3 行忘了加 import |

## 第 4 步：把数据放进界面

**目标**：卡片真正显示网上的句子，刷新一次换一句。

**改哪里**：第 3 步的 `console.log(data);` 这一行，替换成两行：

```tsx
        setQuote(data.hitokoto);
        setSource(data.from);
```

**验收**：保存 → 卡片显示一句真实的话 + 出处 → 按 F5 刷新，句子变了。

**要求**：先把第 3 步的 `console.log(data)` 留着跑一次，确认字段名是 `hitokoto` 和 `from`，再改。**看着数据写代码**，这是最重要的习惯。

---

## 第 5 步：处理"加载中"和"失败了"

**目标**：网络断了的时候，页面别一直转圈。

**改哪里**：把第 3 步里的 `catch` 块改成：

```tsx
      } catch (error) {
        console.error(error);
        setQuote("加载失败，稍后再试");
      }
```

**验收**：把电脑断网（或把 URL 改成 `https://v1.hitokoto.cn/xxx`），刷新 → 卡片显示「加载失败，稍后再试」，页面其他部分照常。改回来再刷新 → 恢复正常。

这个"故意弄坏一次"的练习很值——真实项目里 80% 的时间在处理意外。
